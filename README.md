# 📽️ SanichPoint Studio — Конструктор Презентаций

Полноценное визуальное приложение на **GO** в стиле PowerPoint для создания интерактивных презентаций в вашем фирменном дизайне, с произвольным размещением блоков на 16:9 холсте, пакетной вставкой фотографий, сменными цветовыми стилями (Красный, Золотой, Синий и др.) и встроенным голосовым управлением.

---

## 🛠️ Главные возможности SanichPoint

### 1. Визуальный 16:9 холст (как в PowerPoint)
* **Свободное перемещение объектов**: хватайте мышкой любой текст, заголовок, карточку или фотографию и ставьте в любую точку слайда.
* **8 маркеров изменения размера**: тяните за синие маркеры по углам и сторонам для растягивания или сжатия объектов.
* **Снятие выделения в один клик**: кликните в **любое свободное место внутри слайда** или вокруг него — выделение тут же снимется.
* **Прямой ввод текста**: кликните по любому тексту на слайде и редактируйте его на месте (`contenteditable`).
* **Полный набор горячих клавиш**:
  * <kbd>Delete</kbd> / <kbd>Backspace</kbd> — удалить выделенный объект.
  * <kbd>Ctrl+Delete</kbd> — удалить текущий слайд (с подтверждением).
  * <kbd>Ctrl+C</kbd> / <kbd>Ctrl+V</kbd> — копировать и вставить объект со смещением.
  * <kbd>Ctrl+D</kbd> — быстрое дублирование выделенного объекта или слайда.
  * <kbd>Стрелки</kbd> — точная подгонка позиции на 1% (с зажатым <kbd>Shift</kbd> — на 5%).
  * <kbd>[</kbd> / <kbd>]</kbd> — опустить ниже / поднять выше слой объекта (z-index).
  * <kbd>F5</kbd> — мгновенный запуск слайд-шоу с микрофоном.
  * <kbd>Ctrl+S</kbd> — окно быстрого экспорта на флешку.
  * <kbd>Escape</kbd> — закрыть слайд-шоу / закрыть окно экспорта / сбросить выделение.
  * <kbd>←</kbd> / <kbd>→</kbd> (когда ничего не выделено) — переключение слайдов.

### 2. Пакетная загрузка множества фотографий на слайд
* Кнопка **«+ Фото (пакетно)»** позволяет выбрать **сразу несколько файлов с компьютера** (с зажатым `Ctrl` или `Shift`).
* Также работает **Drag-and-Drop нескольких файлов**: просто выделите пачку фото на рабочем столе и перетащите на 16:9 холст.
* Каждая фотография создается отдельным объектом на слайде, раскладывается каскадом и автоматически копируется в папку `assets/`.
* У каждой фотографии можно менять размер, перемещать, указывать подпись и запасную ссылку (`fallback`).

### 3. Открытие и Экспорт файлов HTML
* **Кнопка «Открыть HTML»**: принимает только файлы `.html` / `.htm`. Встроен **алгоритм строгой проверки сигнатуры** (`sanichpoint-data`): если файл создан сторонней программой или написан не по нашему формату, приложение покажет предупреждение и защитит проект от поломок.
* **Защита расширения `.html`**: в окне экспорта расширение `.html` вынесено в отдельный защищенный блок — стереть его случайно невозможно, файл гарантированно откроется на любом ПК и флешке.

### 4. Палитра цветов (включая Красный)
* 🔴 **Императорский рубин (Красный)** — насыщенный благородный темно-красный стиль, неоновые акценты.
* 🟡 **Золото и винтаж (стиль Тито)** — оригинальное золото `#D4A359`.
* 🔵 **Деловой сапфир**, 🟢 **Изумруд**, 🟣 **Аметист**, 🔷 **Киберпанк**, ⚪ **Титан**.

### 5. Автономный экспорт на флешку
По нажатию на **«🚀 Экспорт презентации»**:
* Генерируется чистый автономный `.html` файл и папка `assets/` со всеми фото.
* Скопируйте их на **флешку** и открывайте на любом компьютере в браузере.
* Встроено управление голосом через микрофон:
  * **«Дальше»**, **«Далее»**, **«Вперёд»** ➔ следующий слайд.
  * **«Назад»**, **«Предыдущий»** ➔ предыдущий слайд.
  * **«Конец»**, **«Закрой»** ➔ экран завершения доклада.
  * Полноэкранный режим и управление клавишами (`→`, `←`, `Пробел`).

## 📦 Сборка из исходников (Developer Build)

### Требования:
- **Go 1.22+**
- Windows 10 / 11 (WebView2 встроен по умолчанию)

### Инструкция по сборке:
```bash
# 1. Клонирование репозитория
git clone https://github.com/pavlyska/SanichPoint.git
cd SanichPoint

# 2. Установка утилиты для вшивания иконки Windows
go install github.com/tc-hib/go-winres@latest

# 3. Генерация ресурсов Windows (иконка и GUI манифест)
go-winres simply --icon icon.ico --manifest gui --arch amd64

# 4. Сборка исполняемого файла (без черного окна консоли)
go build -ldflags "-H=windowsgui -s -w" -o presentation-builder.exe .
```
