# 📽️ SanichPoint Studio — Конструктор Презентаций и AI-Генератор

**SanichPoint Studio** — это современное визуальное десктопное приложение на **Go + WebView2** для создания премиальных интерактивных презентаций в стиле PowerPoint. 

Приложение сочетает в себе свободный визуальный 16:9 холст, встроенное **голосовое управление докладом через микрофон**, пакетную работу с фото, экспорт презентаций «под ключ» на флешку и **умную интеграцию с любыми нейросетями (ChatGPT, Claude, DeepSeek)** через компактный формат `SANICHPOINT_AI`.

---

## 🌟 Ключевые возможности

### 1. 🤖 Генерация презентаций через AI (Кнопка «✨ AI Презентация»)
* В приложение встроен мгновенный парсер компактного кода `SANICHPOINT_AI`.
* Вместо генерации огромного HTML-кода нейросеть выдает чистый, емкий сценарий на 40–70 строк с темами, раскладками, тезисами и фото.
* Встроен интеллектуальный движок верстки **Zero Overlap**:
  * Автоматический расчет высоты блоков по объему текста.
  * Защита от наезжания текста на фото и карточки.
  * Гарантированный порядок блоков (заголовок и вводный текст всегда выше списков).

### 2. 🧠 Официальный AI-скилл (`SanichPointAISkill/SKILL.md`)
В репозитории есть готовый системный промпт/скилл — [SanichPointAISkill/SKILL.md](../SanichPointAISkill/SKILL.md).
* **Для чего нужен**: обучает любую нейросеть (ChatGPT, Claude, DeepSeek, Antigravity, Cursor) генерировать идеальные презентации для SanichPoint.
* **Как пользоваться**:
  1. Скопируйте текст из `SanichPointAISkill/SKILL.md` в ChatGPT или Claude.
  2. Напишите тему: *«Сделай презентацию на тему: Освоение космоса и Юрий Гагарин»*.
  3. Вставьте полученный блок `SANICHPOINT_AI` в SanichPoint по кнопке **«✨ AI Презентация»** — готовая презентация развернется за секунду!

---

### 3. 🖥️ Визуальный 16:9 холст (как в PowerPoint)
* **Свободное перемещение объектов**: перетаскивайте мышкой любые заголовки, бейджи, текст, карточки и фотографии в любую точку слайда.
* **8 маркеров изменения размера**: изменяйте ширину и высоту карточек и картинок прямо на экране.
* **Инлайн-редактирование текста**: кликните дважды по любому тексту или цифре на слайде и редактируйте на месте (`contenteditable`).
* **Снятие выделения в один клик**: клик в свободное пространство слайда мгновенно снимает выделение и рамки.
* **Полный набор горячих клавиш**:
  * <kbd>Delete</kbd> / <kbd>Backspace</kbd> — удалить выделенный элемент.
  * <kbd>Ctrl+C</kbd> / <kbd>Ctrl+V</kbd> — копировать и вставить блок со смещением.
  * <kbd>Ctrl+D</kbd> — дублировать выделенный объект или слайд.
  * <kbd>Стрелки</kbd> — точная подгонка позиции на 1% (с зажатым <kbd>Shift</kbd> — на 5%).
  * <kbd>[</kbd> / <kbd>]</kbd> — опустить ниже / поднять выше слой объекта (z-index).
  * <kbd>F5</kbd> — мгновенный запуск полноэкранного слайд-шоу с микрофоном.
  * <kbd>Ctrl+S</kbd> — быстрый экспорт презентации на флешку.
  * <kbd>Escape</kbd> — закрыть слайд-шоу / окно экспорта / сбросить выделение.
  * <kbd>←</kbd> / <kbd>→</kbd> — листание слайдов (когда ничего не выделено).

### 4. 🎤 Голосовое управление докладом через микрофон
Во время показа презентации спикеру больше не нужен кликер:
* Кнопка **«🎤 Включить режим голоса»** активирует встроенное распознавание речи (Web Speech API).
* Голосовые команды во время речи:
  * **«Дальше»**, **«Далее»**, **«Вперёд»**, **«Следующий»** ➔ переход к следующему слайду.
  * **«Назад»**, **«Предыдущий»**, **«Верни»** ➔ возврат на слайд назад.
  * **«Сначала»**, **«Старт»** ➔ переход на первый титульный слайд.
  * **«Конец»**, **«Закрой»**, **«Завершить»** ➔ открытие финального экрана «Доклад окончен. Спасибо за внимание!».

---

### 5. 📸 Пакетная загрузка фотографий (Multi-Photo)
* Кнопка **«+ Фото (пакетно)»** позволяет выбрать сразу пачку картинок с компьютера (`Ctrl` или `Shift`).
* Поддерживается **Drag-and-Drop**: перетащите группу фото из проводника прямо на слайд.
* Каждое фото создается отдельным объектом с рамкой, подписью и защитой от ошибок (`fallback`).
* Все локальные фотографии автоматически упаковываются в папку `assets/`.

### 7. 🚀 Автономный экспорт на флешку (Один HTML-файл)
По кнопке **«🚀 Экспорт презентации»**:
* Создается чистый автономный HTML-файл доклада и локальная папка `assets/` со всеми медиа.
* Презентацию можно скопировать на **флешку** и открывать **на любом чужом компьютере** без установки SanichPoint и без интернета!
* Экспортированный доклад полностью сохраняет голосовое управление, дизайн, анимации и горячие клавиши.

## 🏗️ Архитектура приложения

* **Ядро бэкенда**: Go (Golang) — встроенный быстрый HTTP-сервер, раздача статики через `embed.FS`, генератор автономного HTML.
* **Десктопная оболочка**: [go-webview2](https://github.com/jchv/go-webview2) — нативное окно Microsoft Edge WebView2 (без тяжелого Electron).
* **Фронтенд конструктора**: Vanilla JS + TailwindCSS + интерактивный Canvas с Container Queries (`cqw`) для адаптивности 16:9.
* **Ресурсы Windows**: иконка приложения и GUI-манифест вшиты непосредственно в бинарник через `.syso`.

## 🛠️ Сборка исполняемого файла (`.exe`)

В репозиторий включены готовые автоматические скрипты сборки:

### Вариант 1. Через `build.bat` (Двойной клик)
Просто запустите [build.bat](build.bat) двойным кликом в Проводнике Windows:
* Проверит компилятор Go.
* Соберет оптимизированный `SanichPoint.exe` (~7.2 МБ) без черного окна консоли.
* Предложит сразу запустить приложение по нажатию `Enter`.

### Вариант 2. Через PowerShell (`build.ps1`)
В терминале PowerShell доступны удобные флаги:
```powershell
# Обычная сборка
.\build.ps1

# Собрать и сразу запустить
.\build.ps1 -Run

# Собрать в режиме отладки (с окном консоли для просмотра логов Go-сервера)
.\build.ps1 -DebugConsole -Run
```

### Вариант 3. Ручная сборка через консоль
```bash
go build -ldflags "-H=windowsgui -s -w" -o SanichPoint.exe .
```
